# 3sec + Caption— Framework Guidelines

PURPOSE\
Ultra-short viral reel (≈15 seconds) designed for fast emotional hit and
shareability.\
\
CORE RULES\
• One idea only\
• One sentence per beat\
• No teaching, only insight\
• Ends with a line people want to send\
- Long Caption, Very Deep, viral, to the point, not general talk.\
\
STRUCTURE\
1. Hook (shock / mirror)\
2. Value Line (reframe)\
3. Action Nudge (implied, not detailed)\
4. Viral Ending (shareable truth)\
\
DO\
• Be sharp\
• Be human\
• Be uncomfortable\
\
DON’T\
• Explain\
• Teach\
• Stack ideas\
\
PROMPT\
Using 15.viral.01, write a 15-second script about ONE idea only.
Palestinian dialect.
