# Voice & Performance Calibration — v1

**Source:** Moataz Mashal exports — Instagram (Jan–May 2026), Facebook (May 2025–May 2026), TikTok (May 2025–May 2026, 196 videos), YouTube (501 videos). Engagement = likes+shares+comments+saves; ER = engagement/views.

> Purpose: ground the HCS records, the Planner's format/length rules, and the Analytics Repo in what *actually* performs for this audience — not assumptions.

---

## 1. Headline findings

1. **Carousels over-perform on reach.** IG median: carousel **131K** vs reel **60K** vs image **58K**. FB: carousel **150K** vs reel **85K**. Yet the canon allocates only 3 carousels/14 per week. **Recommendation: test raising carousel share** — they're your highest-reach unit.
2. **Short wins.** IG median views by duration: 0–15s **77K**, 16–30s **87K**, then declines (31–60s 66K, 61–120s 60K). YouTube Shorts (<60s) dominate engaged views with **66–86% retention**; the one long video (632s) retained only **34%**. **Recommendation: default video ≤30s; reserve long-form for deliberate exceptions.**
3. **The same hook wins everywhere.** "كل واحد بحياتك هو رسول برسالة" was a top post on IG (529K), FB (529K), and TikTok (925K). Cross-posting compounds — but TikTok median (20K) is far below FB (96K)/IG (65K), so **TikTok is the volume/discovery play, FB+IG the reach engine.**
4. **Belief-collision + painful-truth hooks are the real winners** (see §3). This validates CANON-013's "Collision" and "Painful Truth" as the workhorses; "The Command" appears mainly as *secondary* CTAs, not openers.
5. **Pillar resonance matches the calendar weighting.** Top posts cluster in P1 (self/identity/time), P2 (relationships), P3 (parenting), with P5 (meaning) spiking hard when present. This corroborates the CANON-015 distribution (P1=22, P2=17, P3=9) — the methodology is already aimed where the audience responds.

## 3. Voice patterns (extracted from real top captions)

These are the patterns the Script Agent should imitate; they're consistent with CANON-012/013 and now evidenced.

- **Address one person, second-person, often a question or challenge:** "شو بتعمل بهاد الوقت؟!" · "عندك هاد الصديق؟" · "مريت بهاي المرحلة مع أطفالك؟"
- **Belief-collision openers (Collision / Painful Truth):** "اكبر كذبة، انك لازم إتضلك مشغول عشان تنجح" · "اللي بتسميه شخصيتك يمكن يكون بس وضع طارئ" · "الصمت في العلاقة أخطر من الخناق".
- **Spiritual reframe (P5) that travels:** "وعود ربانية تخليك تتأكد إنه بعد كل ألم..." · "في أشي اكبر، اكبر بكثير من كل هذا" · "الله هيك كاتبلي".
- **Explicit save/share CTAs drive distribution:** "ابعت هاد الفيديو للشخص اللي لازم يسمعه" · "كمّل الفيديو ليصلك PDF" · "شاركها معنا بالتعليقات". (Use as *closers*, per the Command hook — not openers.)
- **Confirmed Palestinian-dialect markers:** هاد/هاي، إتضلك، بتعمل، اللي، عشان، بدون، احكيله، سويله، مريت، إنه/إنو. The seed records align; native review should preserve these.

**Calibration flag for the canon:** CANON-013 sets the first line at **3–7 words**, but the *first line of top-engagement posts* runs **8–11 words median** (FB ~8, IG ~11). Two readings: either the rule is stricter than reality, or "first line" = the punchy clause inside a longer opening sentence. **Action:** treat 3–7 words as the *spoken hook* (first ~2 seconds) and allow the written caption's first line to run longer; A/B test in Phase 4.

## 4. Format & length rules for the Planner (data-backed)

- **Default video length ≤ 30s**; flag anything >60s for explicit justification.
- **Weight carousels up** where the goal is reach/saves (tool-delivery HCS, L3 Key).
- **Cross-post the winners** but localize: TikTok titles shorter/punchier; FB/IG carry the full caption-script.
- **Hook = belief collision or painful truth** for P1/P2; **spiritual reframe** for P5; questions for P3.
- **Always close with a save/share command** (the orphaned "Command" hook type finds its home here).
