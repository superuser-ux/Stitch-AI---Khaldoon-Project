# CANON-014 — Content Formats

## Canonical Formats
| Format | Use Case | Lens Fit | Production Notes |
|---|---|---|---|
| Reel — Studio | Precise, planned, high-weight message | Earthquake, Mirror | Clean background, professional lighting, scripted. |
| Reel — iPhone | Raw, intimate, late-night one-person message | Deep | Do not overproduce. Imperfection is part of the message. |
| Reel — Podcast | Conversational, question-led, intimate | Story, Key | The question must crack the wound open. |
| Reel — Event Cut | Social proof, scale, credibility | Story, Earthquake | Real footage, real crowd, real transformation. Minimum once per week. |
| Carousel | Tool delivery, structured insight | Key | Slide 1 must work as a standalone Reel hook. Last slide is micro-solution. |
| Pic + Caption | Visual stop + full spoken script in caption | Flexible | Caption is the script. Last line is the most important line. |
| 3sec Reel + Caption | Ultra-short visual stop + full caption script | Flexible | Caption carries the real content. |

## Note on Source Naming
Some source material refers to `THE 6 CONTENT FORMATS` while separating `Pic + Caption / 3sec Reel + Caption` into one combined category. The 28-day calendar operationally uses 7 scheduled format slots.

## Agent 1 Rule
Agent 1 must select format based on HCS + lens + platform + calendar distribution, not personal preference.
