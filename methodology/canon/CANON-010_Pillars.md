# CANON-010 — Pillars

## Canonical Pillar Model
The active system uses 5 pillars.

| Code | Pillar | Arabic | Canonical Scope |
|---|---|---|---|
| P1 | Self | النفس | Inner experience, emotions, beliefs, identity, stress, shame, fear, self-worth, control, grief. |
| P2 | Relationships | العلاقات | Marriage, partner choice, emotional needs, boundaries, conflict, betrayal, family interference. |
| P3 | Parenting | الأبوة والأمومة | Parenting fear, burnout, identity loss, inherited patterns, tools, teenagers, screens, marriage impact. |
| P4 | Work | العمل | Career identity, betting on oneself, visibility, exhaustion, stagnation, work-life collapse. |
| P5 | Meaning / العلاقة مع الله | العلاقة مع الله | Spiritual emptiness, worship presence, guilt, tawakkul, existential questions, death and afterlife. |

## Supersession Rule
The 5-pillar model supersedes earlier references to a 4-pillar Soul Architecture framing for this implementation cycle. The current active pillar set is P1-P5.

## Agent 1 Rule
Every content slot must be assigned exactly one primary pillar. A secondary pillar may be noted, but scheduling and HCS assignment must use the primary pillar.
