# CANON-013 — Hook Types

## The 5 Hook Types
| Hook Type | Function |
|---|---|
| Painful Truth | Names what the viewer feels but has never heard said out loud. |
| The Collision | Breaks a belief so completely the brain cannot scroll past. |
| The Drop | Opens in the middle of a real moment: specific, unresolved, sensory. |
| The Promise | Creates a gap the brain must close: numbered or proof-based. |
| The Command | Direct instruction; the brain executes before it evaluates. |

## Non-Negotiable Hook Rules
- First sentence: 3 to 7 words maximum.
- No greeting.
- No warm-up.
- No `today I want to talk about` framing.
- Specific always beats general.
- Address one person, not an audience.
- The hook must be true, not merely clever.

## Hard Fail Conditions
- Hook starts with greeting.
- Hook starts with Moataz's name.
- Hook is generic motivational language.
- Hook speaks to an audience instead of one person.
- Hook is clever but not true.
